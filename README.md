# RTI-Documentacion

Documentación auxiliar, análisis, correcciones, decisiones y seguimiento del Reporte Técnico de
Investigación de Xavier Eduardo Antonio Sánchez. **No es el documento académico** — el documento
académico vive en un repositorio aparte: `RTIExperienciaProfesional2026`.

Empieza aquí:

1. **`CLAUDE.md`** — reglas permanentes de cómo trabajar en este proyecto (léelo primero si eres
   una sesión nueva de Claude).
2. **`contexto/CURRENT_STATUS.md`** — en qué punto está el trabajo ahora mismo.

Estructura:

- `contexto/` — qué es el proyecto, estructura del documento, plan de fases, estado actual.
- `correcciones/` — comentarios del asesor y guía detallada de corrección por cada uno.
- `analisis/` — diagnóstico académico y de compilación LaTeX.
- `bibliografia/` — auditoría de referencias.
- `seguimiento/` — bitácora de sesiones (`CHANGELOG.md`).
